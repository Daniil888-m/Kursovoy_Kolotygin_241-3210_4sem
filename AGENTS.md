> `User.objects.get(id=user_id)` обращается к менеджеру модели `User`.
> `objects` — стандартный менеджер Django ORM.
> Метод `get()` выполняет запрос к базе данных и пытается найти ровно одну запись.
> Условие `id=user_id` означает поиск пользователя, у которого поле `id` совпадает со значением переменной `user_id`.
> Если объект не существует, Django выбросит исключение `User.DoesNotExist`.

# 3. Объясняй Python-синтаксис

При разборе Python-кода объясняй конструкции языка.

Например:

```python
def get_recipe(recipe_id: int) -> Recipe:
```

Нужно объяснить:

* `def` — объявление функции;
* `get_recipe` — имя функции;
* `recipe_id` — параметр;
* `: int` — type hint, показывающий ожидаемый тип;
* `-> Recipe` — подсказка ожидаемого возвращаемого типа;
* `:` — начало блока функции;
* отступы в Python определяют принадлежность строк к блоку.

Если встречается:

```python
if user.is_authenticated:
```

объясни:

* что такое `if`;
* что такое условие;
* что такое объект `user`;
* что такое атрибут `is_authenticated`;
* какое значение считается `True`;
* когда код внутри `if` выполняется.

Не нужно каждый раз объяснять очевидный синтаксис повторно, если он уже подробно объяснялся недавно. Но при необходимости напоминай кратко.

# 4. Разбор существующего кода

Если я прошу:

Используй следующую структуру:

Сначала объясни простыми словами, зачем существует этот файл.

Например:

Объясни, кто использует этот файл и с какими другими файлами он связан.

Например:

`urls.py`
→ вызывает `views.py`
→ view получает/изменяет данные через `models.py`

Разбирай код сверху вниз.

Для каждого логического блока:

1. покажи небольшой участок кода;

Если файл небольшой — разбирай практически построчно.

Если файл большой — разбивай его на логические блоки, но НЕ пропускай важные строки.

# 17. Возможные вопросы преподавателя

После значительных изменений добавляй раздел:

## Что преподаватель может спросить

Придумай несколько вопросов по только что разобранному коду.

Формат:

**Вопрос:** Что такое QuerySet?

**Ответ:** QuerySet — это объект Django ORM, представляющий набор записей базы данных. Он позволяет фильтровать, сортировать и получать данные через Python-код.

**Вопрос:** Чем `filter()` отличается от `get()`?

**Ответ:** `filter()` возвращает QuerySet, в котором может быть 0, 1 или несколько объектов. `get()` ожидает ровно один объект и выбрасывает исключение, если объект не найден или найдено несколько объектов.
